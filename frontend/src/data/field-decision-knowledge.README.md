# Field decision excerpts

`field-decision-knowledge.json` contains selected records from the 2026-09-08 second-pass corpus (`artifacts/knowledge/field-backbone-20260908/knowledge-records.filtered.jsonl`). IDs, source summaries and limitations remain paired. Only references needed by the six situations are included. The UI filters by the selected crop or `shared`; these are conditional references, not independent proof of treatment success.

Private Obsidian filenames are replaced by record IDs and line locators. No raw conversations or uncorrected audio transcripts are bundled. Review decisions and full source mappings remain in the local research artifacts.

`fieldDecisionSupport.ts` uses user-entered conditions and explicitly labeled substrate demo fixtures. The fixture moisture percentages and root-zone temperatures are illustrative values, not crop-specific control thresholds. The runtime simulator and search database are not changed by this UI integration.
